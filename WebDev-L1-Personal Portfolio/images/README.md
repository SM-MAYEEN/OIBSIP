The portfolio currently uses `profile.jpg` for the hero portrait and the three `project-*.jpg` files for the matching project previews. The original uploads are kept in `../asset/`.

Replace `profile.jpg` to change the portrait. Replace a project preview in `sections/projects.html` to change the corresponding screenshot. The `gallery-*.svg` files remain placeholders for personal photos; when adding gallery images, update both the `src` and `data-image` paths in `sections/gallery.html`.
